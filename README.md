## Project Overview

This project is a desktop-based Employee Management System developed
as part of a Total Quality Management project.

The baseline application provides essential employee management
functions.

The major objective of the project is not to create a highly complex
Employee Management System, but to improve the reliability of the
baseline system using Total Quality Management principles.

---

## Reliability Improvements

The project focuses on the following improvements:

1. Automatic Database Backup
2. Audit Logging
3. Input Validation
4. Error Handling and Recovery
5. Role-Based User Access

Additional reliability metrics will also be shown through a dedicated
Reliability Dashboard.
